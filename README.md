## 🌟 Sections & Features

### 1. ASCII Numbers
- Convert entered text into its ASCII numerical representation in real-time.
- Responsive table with columns: **Character**, **Decimal**, **Hex**, **Binary**, and **Octal**.
- Shows character count, word count, and byte size.

### 2. ASCII Table
- Full standard ASCII reference table from **0–127**.
- Columns: **Decimal**, **Hex**, **Character**, **Binary**, and **Octal**.
- Control characters clearly identified (`NUL`, `SOH`, `STX`, `ETX`, `EOT`, `ENQ`, `ACK`, `BEL`, `BS`, `TAB`, `LF`, `VT`, `FF`, `CR`, `SO`, `SI`, `DLE`, `DC1`, `DC2`, `DC3`, `DC4`, `NAK`, `SYN`, `ETB`, `CAN`, `EM`, `SUB`, `ESC`, `FS`, `GS`, `RS`, `US`, `DEL`).
- Printable characters rendered directly.
